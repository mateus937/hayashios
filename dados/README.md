# dados/ — entrada

Solte aqui o que você quer que o HayashiOS leia: planilha de RH ou de
segurança, export de sistema, PDF, print, vídeo bruto pequeno, lista do
mês. `/analisar-dados` olha esta pasta primeiro.

Esta pasta **não vai pro repositório** (`.gitignore`): planilhas com dados
de colaboradores podem ficar aqui sem subir. Não é arquivo final; o que
importa vira análise em `saidas/` ou material em `materiais/`.
