# saidas/ — análises, e-mails e registro

```
saidas/
├── analises/<YYYY-MM-DD>-<nome>.md     /analisar-dados
├── emails/<YYYY-MM-DD>-<assunto>.md    /email-profissional (quando salvo)
├── registro/<slug>.md                  uma linha por coisa feita, por pessoa (sem nomes de terceiros)
└── outros/                             o que não couber nas pastas padrão
```

O registro alimenta o `/abrir` e o `/atualizar`. Cada pessoa escreve só no
próprio arquivo, o que evita conflito no `/salvar`.
