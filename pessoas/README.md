# pessoas/ — só no seu computador

Materiais que falam de pessoas específicas: orientações do `/decisao`,
roteiros e registros de `/feedback`, listas de aniversariantes, termos e
listas preenchidos, análises nominais.

Esta pasta **não vai pro repositório** (está no `.gitignore`). Fica no
computador de quem gerou. Mesmo aqui, o padrão é usar papéis e primeiro
nome, sem CPF, telefone, saúde ou vida pessoal.

```
pessoas/
├── decisoes/<YYYY-MM-DD>-<slug>.md
├── feedback/<YYYY-MM-DD>-<slug>/
└── outros/
```
