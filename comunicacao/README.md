# comunicacao/ — o que a Hayashi comunica

```
comunicacao/
├── calendario/<YYYY-MM>.md                planejamento do mês (/calendario)
├── comunicados/<YYYY-MM-DD>-<slug>/       /comunicado (texto.md, whatsapp.md, mural.png, oficial.pdf, email.md)
└── redes/<YYYY-MM-DD>-<slug>/             /carrossel (meta.md com aprovado_por, instagram/*.png, legenda.md)
```

Tudo aqui é da empresa e vai pro repositório pelo `/salvar`. Material pra
fora da empresa fica em `redes/` com `aprovado_por` preenchido antes de
qualquer publicação (arquétipo VI).
