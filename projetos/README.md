# projetos/ — frentes com começo, meio e fim

Uma pasta por frente (SIPAT, confraternização, campanha, programa 5S, nova
unidade), criada pelo `/novo-projeto`, com `CLAUDE.md` próprio e
`briefing.md`. As peças continuam saindo em `comunicacao/` e `materiais/`;
aqui ficam briefing, cronograma, decisões e links.

```
projetos/<YYYY-MM>-<slug>/
├── CLAUDE.md
├── briefing.md
└── (subpastas só das entregas pedidas)
```
